# CCNA Packet Tracer Labs

This repo has my **Cisco Packet Tracer** (`.pka`) lab files from the
**Cisco CCNA module**. I finished my second year as software engineer and these are the
hands-on exercises I completed throughout the course

## What's in here

The labs are organized by lab session, with each session grouped into the
course modules it covers:

| Folder | Modules | Topics |
|--------|---------|--------|
| `lab1` | mod1–3   | Basic device config, Cisco IOS, protocols & models |
| `lab2` | mod4–5   | Physical layer, number systems, data link layer |
| `lab3` | mod6–7   | Ethernet switching |
| `lab4` | mod8–9   | Network layer, address resolution (ARP) |
| `lab5` | mod10–12 | Router config, IPv4 subnetting & VLSM, IPv6 addressing |
| `lab6` | mod13–15 | ICMP, ping/traceroute, transport layer (TCP/UDP), app layer |
| `lab7` | mod16–17 | Network security fundamentals, build & troubleshoot a network |
| `rc cache` | — | Physical-mode and review/challenge Packet Tracer activities |

Each `.pka` file is named after its corresponding Cisco lab number (e.g.
`11.10.1-packet-tracer---design-and-implement-a-vlsm-addressing-scheme.pka`)
and is opened with Cisco Packet Tracer.

## What I learned from the CiscoCCNA 

- Configuring Cisco routers and switches through the IOS CLI
- The OSI and TCP/IP models and how protocols map to each layer
- Ethernet switching, MAC addressing, and the ARP process
- IPv4 addressing, subnetting, and VLSM design
- IPv6 addressing schemes
- Testing and troubleshooting connectivity with ICMP, `ping`, and `traceroute`
- Transport layer behavior of TCP and UDP
- Network security fundamentals
- Building, verifying, and troubleshooting a small network end to end
